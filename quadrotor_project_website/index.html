Problem Statement

Navigate a restricted airspace and hover at a commanded destination.

The goal is to design controllers and a path planning system for a quadrotor. Given a destination or desired trajectory, the robot must reach the target, stabilize, and track the requested motion using feedback control.

Rigid-body model

The quadrotor is modeled with an inertial frame and a body-fixed frame attached to the center of mass. Translational motion is driven by gravity and the total thrust from four rotors, while rotational motion is driven by roll, pitch, and yaw moments.

Control challenge

A quadrotor can only create thrust along its body z-axis, so the controller must compute both the total thrust magnitude and the desired attitude that points the thrust vector in the direction needed for motion.

Control Architecture

Cascaded outer-loop position control and inner-loop attitude control.

Trajectory Planner
desired position, velocity, acceleration
→
Position Controller
desired thrust + orientation
→
Attitude Controller
roll, pitch, yaw torques
→
Motor Mixer
PWM / RPM commands
→
Quadrotor Dynamics
new state feedback

Outer-loop PD control

Td = Kper + Kdev + mad + Fg

The position controller combines position error, velocity error, desired feedforward acceleration, and gravity compensation.

Inner-loop attitude control

τ = -Kp,atteR + Kd,atteω

The attitude controller uses rotation error and angular velocity error to compute torques for orientation tracking.

Project Development

Built in three phases

01

Phase 1: PD Controller

Implemented position and attitude control in DSLPIDControl.py. The controller was tuned to reach randomly assigned destination positions and hover with an expected settling time of about 5 seconds.

02

Phase 2: Trajectory Mapping

Generated circular and diamond trajectories, including 3D plots, 2D planar projections, and position-velocity-acceleration profiles for each path.

03

Phase 3: Trajectory Tracking

Integrated the trajectory generator with the PD controller and evaluated tracking performance for baseline gains, reduced gains, and shorter trajectory durations.

Trajectory Design

Two paths were used to test different motion requirements.

Circular trajectory

A smooth path with continuous curvature. This trajectory tests whether the controller can track continuous changes in velocity and acceleration.

Diamond trajectory

A piecewise linear path with sharp corners. This trajectory tests how the controller reacts to abrupt direction changes and velocity discontinuities.

Experiments

Tracking performance was studied by changing gains and trajectory duration.

Baseline gains

Position gains used Kp = [0.2, 0.2, 0.25] and Kd = [0.49, 0.49, 0.14]. Attitude gains used Kp,att = [70000, 70000, 50000] and Kd,att = [8000, 8000, 7200].

Gain reduction tests

Kp and Kd were reduced by 30%, 40%, and 50% to observe how proportional and derivative action affect tracking accuracy, overshoot, and response speed.

Duration tests

Trajectory duration was shortened to increase velocity and acceleration requirements. Faster trajectories pushed the controller closer to its limits.

Key Results

Derivative gain had the strongest effect on tracking performance.

TrajectoryBaseline RMSEKd reduced 50%Kp reduced 50%Main observation
Diamond0.0092 m0.0141 m0.0124 mSharp corners increase sensitivity to velocity changes.
Circular0.0127 m0.0239 m0.0146 mContinuous curvature made the circle more sensitive to reduced derivative action.

Kd reduction

Lower derivative gain reduced damping. The circular trajectory RMSE increased from 0.0127 m to 0.0239 m, an 88% increase.

Kp reduction

Lower proportional gain caused slower response and more steady-state error, especially in z, but the effect was less severe than Kd reduction.

Shorter durations

Reducing trajectory time increased acceleration requirements. The diamond path became unstable near sharp vertices, and the circular path approached actuator limits at faster speeds.

Conclusion

What I learned

The cascaded PD controller successfully tracked both circular and diamond trajectories with low baseline error. The experiments showed that derivative gain is critical for damping and velocity-error correction, while proportional gain mainly affects response speed and steady-state error. Faster trajectories demand larger control inputs, so controller performance depends not only on gain tuning but also on the dynamic feasibility of the desired path.
