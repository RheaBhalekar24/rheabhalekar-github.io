# Quadrotor PD Control Website

This folder contains a static GitHub Pages website for the `Quadrotor-PD-Control` repository.

## Files

- `index.html` - main website content
- `style.css` - layout, animation, and responsive styling
- `script.js` - mobile navigation, reveal animation, and copy button

## Deploy on GitHub Pages

1. Copy these files into the root of the GitHub repository.
2. Go to repository Settings > Pages.
3. Select Deploy from a branch.
4. Choose the `main` branch and `/root` folder.
5. Save and wait for GitHub Pages to publish the website.
