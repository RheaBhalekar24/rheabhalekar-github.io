## Prerequisites

Before running the code, ensure that you have the following packages installed:

- **PyTorch** (v2.4.0)
- **NumPy** (v1.26.0)
- **Matplotlib** (v3.8.0)
- **TorchVision** (if needed for additional datasets or transforms)

## Installation

To install the required packages, use the following command:

```bash
pip install torch==2.4.0 numpy==1.26.0 matplotlib==3.8.0 torchvision

## Running the Script

To run the `main.py` script, use the following command in your terminal:

python main.py
