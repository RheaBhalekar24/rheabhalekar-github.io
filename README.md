# Rhea Bhalekar — GitHub Pages Website

This folder contains the full website files.

## Files

- `index.html`
- `assets/style.css`
- `assets/script.js`

## Project icon meanings

Each project has three icons:

- GitHub icon: repository link
- External-link icon: project demo / video / website
- File icon: paper / report / PDF

Replace the `href="#"` values in `index.html` with your real links.

## Publish

Create a repository named:

```text
RheaBhalekar24.github.io
```

Upload these files to the root of the repository and enable GitHub Pages from the `main` branch.
